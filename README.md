
# Simple Interest Calculator

This project contains a simple Bash script to calculate simple interest based on user input.

## Project Details

- **Project Name:** Simple Interest Calculator
- **Programming Language:** Bash
- **Purpose:** To calculate simple interest using principal, rate of interest, and time period.

## Formula

Simple Interest = (Principal × Rate × Time) / 100

Where:
- Principal (P): The original amount of money.
- Rate (R): The annual rate of interest in percentage.
- Time (T): The time period in years.

## Features

- Accepts principal amount from the user.
- Accepts rate of interest from the user.
- Accepts time period in years.
- Calculates and displays simple interest.

## How to Use

1. Clone or download this repository.
2. Open a terminal in the project folder.
3. Run the script:

   ```bash
   bash simple-interest.sh
   ```

4. Enter the principal amount, rate of interest, and time period when prompted.
5. The calculator displays the calculated simple interest.

## Example

Input:
- Principal: 1000
- Rate: 5%
- Time: 2 years

Calculation:

Simple Interest = (1000 × 5 × 2) / 100 = 100

Output:

Simple Interest: 100
